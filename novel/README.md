# Novel

Folder ini berisi naskah, satu folder per bab.

```
novel/
  bab-01/
    v1.md
    v2.md
    ringkasan.md
  bab-02/
    ...
```

Aturan:
- Versi tertinggi (v2 mengalahkan v1) adalah versi aktif.
- Versi lama tidak pernah ditimpa atau dihapus.
- Detail format ada di [INSTRUKSI-GPT.md](../INSTRUKSI-GPT.md).
