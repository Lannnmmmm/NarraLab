# STORY MEMORY — TAKHTA ABU

Folder ini adalah memori kerja ringkas agar penulisan dapat dilanjutkan tanpa membaca seluruh bab dari awal.

## Urutan baca saat melanjutkan
1. `../README.md` — fondasi dan aturan canon.
2. `story-state.md` — posisi cerita terkini.
3. `character-state.md` — kondisi dan pengetahuan karakter.
4. `timeline.md` — kronologi dunia dan cerita.
5. `unresolved-threads.md` — misteri dan konflik yang belum selesai.
6. `last-session.md` — titik terakhir pekerjaan.
7. Ringkasan bab terakhir dan satu atau dua bab sebelumnya.
8. Buka naskah penuh hanya bila perlu memeriksa adegan, dialog, foreshadowing, atau detail kontinuitas.

## Aturan pembaruan
- Perbarui file yang terdampak setelah setiap bab selesai atau direvisi.
- Bedakan fakta canon, fakta yang terjadi di naskah, dan usulan yang belum disetujui.
- Gunakan label **BELUM DITETAPKAN** untuk hal yang belum diputuskan.
- Ringkasan bab mencatat peristiwa; Story Memory mencatat kondisi cerita terkini.
- Cantumkan bab/versi sumber setiap perubahan.
- Jika ada kontradiksi, catat dan minta keputusan Author; jangan memilih diam-diam.

## Siklus setiap bab
1. Simpan naskah bab.
2. Buat/perbarui `chapters/bab-NN/ringkasan.md`.
3. Perbarui Story Memory yang terdampak.
4. Periksa kontinuitas dengan bab sebelumnya dan rencana berikutnya.
5. Perbarui `last-session.md`.

**Status awal:** belum ada bab ditulis. File memori merupakan baseline canon, bukan kejadian dalam naskah.
